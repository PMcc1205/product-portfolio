# Product Portfolio

Static portfolio site for two product-management projects:

- AI Resume Optimization Assistant
- SalesFast Education CRM

The latest AI Resume case study is embedded at `prototypes/ai-resume/portfolio/`. It includes the full case-study page and a static interactive demo at `#/demo`; no API key or backend service is required.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. In the repository, open **Settings > Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then save.

The published URL will normally be `https://<github-username>.github.io/<repository-name>/`.

All project source files are kept under `materials/`. Axure `.rp` files need Axure RP to open. Export each prototype as HTML into `prototypes/<project>/` to enable browser-based interaction.
